## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um portfólio profissional para **Dayane Luz**, estudante do segundo ano de Audiovisual na Universidade Federal de Mato Grosso do Sul (UFMS).

O objetivo do projeto foi criar uma plataforma moderna para apresentação de trabalhos audiovisuais, permitindo que a profissional apresente seus projetos de:

- 🎥 Produção audiovisual
- ✂️ Edição de vídeos
- 📱 Reels e Shorts
- 📸 Edição fotográfica
- 🎞️ Projetos criativos


O site foi desenvolvido buscando equilibrar uma identidade visual delicada e personalizada, preservando características da personalidade da artista através de elementos como:

- Paleta de cores em tons de rosa;
- Ilustrações fofas;
- Elementos inspirados em animais;
- Microinterações;
- Animações suaves;

mantendo ao mesmo tempo uma apresentação profissional adequada para o mercado audiovisual.


---

# ✨ Objetivos do Projeto

- Criar uma presença digital profissional;
- Facilitar a apresentação de trabalhos;
- Valorizar a identidade visual da criadora;
- Criar uma experiência moderna para visitantes;
- Desenvolver uma interface responsiva e intuitiva.

# 🎨 Design e Identidade Visual


O conceito visual foi criado baseado na personalidade da artista:

- Criatividade;
- Delicadeza;
- Expressividade;
- Profissionalismo.


A proposta foi fugir de portfólios genéricos e criar uma experiência que representasse a identidade da Dayane.
